Memos

Impact Score: 80

📋 Product Spec

Memos is a rich-text note-taking panel saved per workspace in WorkLoad Tab. It supports bold, italic, lists, and clipboard image paste. Multiple memos per workspace, reorderable via drag and drop.

💬 User Voice

The notepad that lives right where you work. Paste screenshots, jot meeting notes, save that one command you always forget — all without leaving your new tab page.
